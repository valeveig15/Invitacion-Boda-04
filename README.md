# Martina & Federico · Invitación Uruguay · V23

Versión standalone corregida a partir del diseño botánico Uruguay y la referencia de calidad/animaciones proporcionada.

## Incluye
- Marco botánico visible en portada con movimiento muy suave y profundidad.
- Animaciones de entrada durante el scroll.
- Capilla con icono original del diseño Uruguay y halo/respiración.
- Copas de brindis vectoriales con animación de choque.
- Caja de regalo animada.
- Instagram, dress code, confirmación, canciones e info útil con iconografía y microanimaciones propias.
- Galería sin numeración, con hover y lightbox.
- Cuenta regresiva, música con control flotante y modales funcionales.
- Footer de ArteDeco Studio con wordmark muy destacado.
- Responsive para celular y escritorio.

## Publicación
Subir `index.html`, `style.css`, `script.js` y la carpeta `assets/` a la raíz del repositorio de GitHub Pages.
